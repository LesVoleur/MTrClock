# MTrClock

Показывает местное время компьютера в формате `ЧЧ:ММ` по центру нижней полосы «СООБЩЕНИЯ». Конвертик, счётчик сообщений и уведомления чата используют штатные элементы.

## Установка и проверка

Скопировать папку `mtr_clock` в `extensions` установленной X4 и полностью перезапустить игру. В списке расширений включить «mtr_clock».

Работа текущего варианта в X4 Foundations 9.00 подтверждена автором 23.10.2026. Версия в `content.xml` — `1` (0.01); номер после проверки не менялся. Внешние Mod Support APIs и UI Extensions не нужны.

При скачивании через **Code → Download ZIP** создайте в `extensions` папку `mtr_clock` и скопируйте туда `content.xml`, `subst_01.cat` и `subst_01.dat`. Файл `content.xml` должен лежать непосредственно в `extensions/mtr_clock`. Папка `ui` содержит исходный код; при обычной установке копировать её необязательно.

Для отключения выключить расширение и полностью перезапустить игру. Изменений состояния сохранения мод не вносит (`save="false"`).

## Реализация и ограничения

Исходник `ui/core/lua/monitors.lua` взят из установленной игры, каталог `08.cat`, MD5 исходника `6c9de3306008b77031477bce5825dd2f`. Исполняемый файл `monitors.xpl` в `subst_01.cat/dat` скомпилирован библиотекой LuaJIT этой же установки.

Мод заменяет основной скрипт мониторов HUD. С другими модами, заменяющими `ui/core/lua/monitors.xpl`, он несовместим без объединения изменений. После обновления X4 необходимо сверить исходный скрипт с новой версией.

Отдельный элемент в бинарную сцену HUD не добавляется: часы выводятся в существующем текстовом поле после рассчитанного отступа. Отступ рассчитывается по реальной ширине текста и текущему размеру шрифта. Погрешность центрирования ограничена половиной ширины пробела. Если при большом масштабе интерфейса надпись слева не оставляет места, часы скрываются, чтобы не перекрыть надпись.

Используется `GetDate("%H:%M")`; часовой пояс берётся из системного времени игры, без фиксированного смещения UTC. Проверка времени выполняется примерно раз в секунду работы HUD, строка меняется только при смене минуты или перерасчёте масштаба. Ошибка получения времени отключает часы до повторной инициализации панели и оставляет штатную надпись.

Подробная инструкция с разбором кода по смысловым блокам: [Описание кода](docs/Описание-кода.md).
