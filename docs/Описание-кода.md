# MTrClock: инструкция и описание кода

Дата обновления: 23.10.2026. Игра: X4 Foundations 9.00. Имя расширения: `mtr_clock`. Версия в `content.xml`: **0.01** (`1`).

Ниже код разобран по смысловым блокам. Примеры сокращены до существенных частей; номера строк и технические таблицы не используются.

## Что делает мод

По центру нижней полосы «СООБЩЕНИЯ» в HUD выводится местное время компьютера, например `21:45`. Используется 24-часовой формат без секунд. Часовой пояс не задан числом: время берётся через встроенную функцию игры.

Надпись «СООБЩЕНИЯ» остаётся слева. Конвертик, количество непрочитанных сообщений и уведомления чата используют штатные элементы. Мод не меняет миссии, экономику, корабли и содержимое сообщений.

Часы являются частью штатной панели. Отдельного окна поверх всех экранов не создаётся: видимость зависит от того, отображает ли игра эту панель HUD.

## Установка и отключение

В папку `extensions/mtr_clock` установленной игры положить `content.xml`, `subst_01.cat` и `subst_01.dat`. После установки полностью перезапустить X4 и проверить расширение `mtr_clock` в списке модов.

Для отключения выключить расширение и полностью перезапустить игру. Мод не хранит свои данные в сохранении. Исходные архивы игры не изменяются: активное расширение подменяет файл в виртуальной файловой системе.

## Из каких файлов состоит мод

`content.xml` содержит идентификатор `mtr_clock`, название, автора и версию. Значение `save="false"` означает, что расширение не помечается как обязательная зависимость сохранения. Собственных сохраняемых игровых данных у часов также нет.

`ui/core/lua/monitors.lua` — полный исходный скрипт мониторов HUD с добавленным блоком часов. Большая часть файла относится к самой X4: она обслуживает радар, миссии, сообщения и другие элементы мониторов. Собственный код добавлен к этому скрипту; штатные строки при создании подмены не удалялись.

`subst_01.cat` — текстовое оглавление архива подмены: внутренний путь файла, его размер, время и контрольная сумма MD5.

`subst_01.dat` — содержимое архива. В нём лежит скомпилированный скрипт `ui/core/lua/monitors.xpl`. Файлы `.cat` и `.dat` нужны вместе. `01` — номер архива, а не версия часов.

`README.md` содержит краткое описание и порядок установки. Эта инструкция в репозитории находится в `docs/Описание-кода.md`; её копия в Obsidian — в заметке «Мод MTrClock».

Обычный `ui.xml` для подключения меню здесь не используется: изменяется основной скрипт HUD через архив подмены. Внешние библиотеки модов не требуются.

## Общая схема работы

При загрузке панелей игра использует `monitors.xpl` из архива мода. Штатная инициализация находит текстовое поле полосы сообщений и устанавливает его размер. Добавленный блок запоминает ссылку на поле и сразу выводит время.

Затем штатный обработчик `self:onUpdate()` вызывает функцию часов при каждом обновлении HUD. Внутри неё стоит ограничение частоты: системное время запрашивается примерно раз в секунду работы интерфейса. Если минута и размер шрифта прежние, строка повторно не записывается.

Надпись и часы выводятся в одном текстовом поле. Между ними вставляется рассчитанное количество пробелов, чтобы середина времени пришлась на центр полосы. Элементы конвертика и счётчика сообщений в расчёте и записи текста не участвуют.

## Инициализация часов

```lua
local messageTickerFooterTextElement = getElement(
    "footer.Text", private.anarkElements.messageTicker.mainElement
)
setAttribute(messageTickerFooterTextElement, "textstring", L["MESSAGES"])
setAttribute(messageTickerFooterTextElement, "size", scaleFont(config.footerFontSize))

private.messageTickerClock = { element = messageTickerFooterTextElement }
updateMessageTickerClock(true)
```

Первые действия штатные: найти поле, задать локализованную надпись и размер шрифта. Собственная часть создаёт `private.messageTickerClock` и вызывает обновление с `force = true`, чтобы часы появились сразу.

В этой временной структуре позднее хранятся ссылка на элемент, последнее показанное время, размер шрифта, моменты проверки и признак отключения после ошибки. При повторной инициализации панели структура создаётся заново. В сохранение она не записывается.

Функция заранее объявлена через `local updateMessageTickerClock`, поэтому её определение ниже по файлу относится к локальной переменной этого скрипта.

## Подключение к обновлению HUD

```lua
function self:onUpdate()
    updateMessageTickerClock()
    -- Далее выполняется штатное обновление мониторов X4.
end
```

Добавлен вызов часов в начале существующего обработчика. Остальная логика мониторов выполняется как прежде. Сам обработчик срабатывает часто, но часы большую часть вызовов пропускают по таймеру.

## Ограничение частоты проверки

```lua
local elapsed = getElapsedTime()
if not force and clock.nextUpdate
    and elapsed >= clock.lastUpdate and elapsed < clock.nextUpdate then
    return
end
clock.lastUpdate = elapsed
clock.nextUpdate = elapsed + 1
```

`getElapsedTime()` используется только для интервала между проверками. Он не является источником показаний часов. Следующая проверка назначается через одну секунду времени этого таймера.

Условие `elapsed >= clock.lastUpdate` позволяет продолжить работу при сбросе таймера: если его значение стало меньше предыдущего, функция проверяет время сразу.

Проверки выполняются, пока игра вызывает обновление HUD. Если во время паузы или сворачивания вызовы останавливаются, нового текста в этот момент не будет. При следующей проверке функция вновь получает системное время, а не прибавляет пропущенные секунды самостоятельно.

## Получение реального времени и обработка ошибки

```lua
local ok, currentTime = pcall(GetDate, "%H:%M")
if not ok or type(currentTime) ~= "string"
    or not string.match(currentTime, "^%d%d:%d%d$") then
    clock.disabled = true
    setAttribute(clock.element, "textstring", L["MESSAGES"])
    DebugError("mtr_clock: GetDate did not return local time; clock disabled.")
    return
end
```

`GetDate("%H:%M")` запрашивает местное системное время. `%H` задаёт часы в 24-часовом формате, `%M` — минуты. Игровое время и ускорение SETA в вычислении показаний не используются.

`pcall` перехватывает ошибку именно вызова `GetDate`. Дополнительно проверяются тип результата и форма `две цифры:две цифры`. Это проверка формата, а не отдельная проверка допустимого диапазона часов и минут.

При ошибке восстанавливается штатная надпись, часы отключаются до повторной инициализации панели, а в диагностический журнал один раз попадает сообщение. Последующие вызовы выходят по признаку `clock.disabled`, поэтому ошибка не записывается каждый кадр. Эта защита не является общей обработкой любых ошибок во всём скрипте мониторов.

## Когда нужно менять текст

```lua
local fontsize = scaleFont(config.footerFontSize)
if not force and clock.time == currentTime and clock.fontsize == fontsize then
    return
end
clock.time = currentTime
clock.fontsize = fontsize
```

Базовый размер подписи в штатной конфигурации — `18`. Функция `scaleFont` учитывает `private.textUIScale` и округляет размер вверх. Часы используют тот же шрифт и размер, что и надпись полосы.

Если время и вычисленный размер шрифта не изменились, повторного расчёта отступа и записи строки нет. При смене минуты, изменении размера или принудительном обновлении расчёт выполняется снова.

## Как часы попадают в центр полосы

```lua
local font = getAttribute(clock.element, "font")
local label = L["MESSAGES"]
local labelWidth = C.GetTextWidth(label, font, fontsize)
local clockWidth = C.GetTextWidth(currentTime, font, fontsize)
local spaceWidth = C.GetTextWidth(" ", font, fontsize)

local centre = getAttribute(private.tickerBackgroundElement, "position.x")
local textStart = getAttribute(clock.element, "position.x")
local gap = centre - textStart - labelWidth - clockWidth / 2
```

`C.GetTextWidth` измеряет текст функцией самой игры. Учитываются текущий шрифт, размер и локализованная надпись, а не заранее подобранное число пробелов для русского языка.

Из координаты центра фона вычитаются начало текста, ширина надписи слева и половина ширины часов. Получается ширина пустого промежутка перед временем. Поэтому центрируется само время относительно полосы, а не вся строка «СООБЩЕНИЯ + часы».

```lua
if spaceWidth <= 0 or gap < spaceWidth then
    setAttribute(clock.element, "textstring", label)
    return
end
local spaces = math.floor(gap / spaceWidth + 0.5)
setAttribute(clock.element, "textstring",
    label .. string.rep(" ", spaces) .. currentTime)
```

Если для промежутка нет места либо ширина пробела некорректна, остаётся только штатная надпись. Иначе промежуток переводится в целое число пробелов с округлением к ближайшему.

Поскольку число пробелов целое, центрирование не является попиксельным: расчётная погрешность составляет до половины ширины пробела. Это позволяет использовать штатное поле без изменения бинарной сцены HUD.

## Сборка и дальнейшие изменения

Для первой сборки штатный `monitors.lua` извлечён из `08.cat` установленной X4 9.00. MD5 исходного файла до добавления часов — `6c9de3306008b77031477bce5825dd2f`.

Изменённый исходник скомпилирован через `lua51_64.dll` из той же установки игры. Это библиотека LuaJIT: она проверила синтаксис и сформировала исполняемый файл для пути `ui/core/lua/monitors.xpl`. Затем файл упакован в `subst_01.dat`, а размер и MD5 записаны в `subst_01.cat`.

Редактирования одного `ui/core/lua/monitors.lua` для обновления установленного мода недостаточно. После изменения кода нужно заново скомпилировать подмену, обновить оба архивных файла и полностью перезапустить игру.

Мод заменяет основной скрипт мониторов целиком, хотя собственных добавлений немного. Если другой мод подменяет тот же `monitors.xpl`, изменения нужно объединять. После обновления X4 следует взять актуальный штатный исходник и перенести в него блок часов, чтобы старая подмена не перекрыла новые исправления HUD.

## Что проверено

Макс подтвердил, что текущий вариант работает в игре. Отдельно проверены компиляция и чтение упакованного байткода библиотекой LuaJIT из X4, соответствие размера и MD5 архивному оглавлению, а также совпадение исходников с установленным модом.

В проверке функции с подставленными интерфейсами игры разобраны смена минуты и переход через полночь, ограничение частоты вызовов, изменение масштаба, сброс таймера, нехватка места и ошибка получения времени. Такая проверка подтверждает логику этих ветвей, но не заменяет визуальную проверку всех разрешений, языков и сочетаний модов.
